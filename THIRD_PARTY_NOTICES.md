# Third-party notices

## Tart

TartUI is a graphical interface for the official Tart virtualization runtime from
https://github.com/openai/tart.

TartUI does not vendor or compile Tart source code.

Users may provide their own Tart installation. When the managed-runtime feature
is used, TartUI downloads an official Tart release artifact and verifies the
published checksum when available as well as the macOS code signature before
using it.

Tart and its release artifacts are distributed under the license published by
the Tart project. The upstream repository and release artifact remain the
authoritative sources for Tart licensing and notices.

## Relationship to Tart
